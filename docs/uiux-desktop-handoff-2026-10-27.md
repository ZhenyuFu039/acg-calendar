## 改动

### U01 · 常用功能直达

- 新文件 `desktop/CalendarWindow.QuickActions.cs`：窗口底部固定快捷栏，**普通列表、透明气泡、月历三种模式都显示**，依次是：
  - `气泡`：直接切换。当前为气泡时显示 `✓ 气泡` 并用强调色，提示文字分别说明“当前模式”和“点击后切换到什么”。
  - `⟳ 同步`：同步当前游戏组合。进行中显示 `⟳ 同步中` 并暂时不可点；悬停提示和无障碍名称包含同步范围与阶段文字（复用 `SyncProgressText`），限流与冷却不变。
  - `完整日历 ↗`：按约定打开 `?game=<scope>&view=timeline`，选了日期时追加 `&date=YYYY-MM-DD`。侧栏和托盘菜单的同一入口也改用这个链接（原来只带 `game`）。
  - `置顶`：显示文字状态（置顶 / 已置顶）。
  - `更多`：打开侧栏（游戏组合与筛选、外观尺寸、提醒、采集、收起与退出）。
- 月历窗口标题栏原来的第二个图钉已删除，统一使用快捷栏里的那一个。右键菜单和托盘菜单保留，作为辅助入口。
- 快捷栏上方新增一行短提示（6 秒后消失，`AutomationLiveSetting.Polite`），用于模式切换、同步开始、关闭与自动保存的反馈。提示自带主题底色，透明气泡下压在任何壁纸上都可读。

### U10 · 原生设置层级

- 外观页顺序改为：保存说明 → **窗口模式**（气泡开关、透明度）→ **挂件尺寸** → **关闭与常驻** → **主题与布局（高级）** → 程序（收起到托盘 / 退出）。主题、模块布局、颜色入口从页首移到后面（`BuildThemeSettings()`，由 `BuildWorkspaceSettings()` 拆出；采集页拆为 `BuildNetworkPage()`，内容和顺序不变）。
- 侧栏四个页面仍共用一个滚动容器，但改为**按页记住各自的滚动位置**：第一次打开的页面从顶部开始，回到某页时恢复它自己上次的位置。

### U13 / U14 · 命名、状态与可读性

- 收起侧栏时的窄工具轨道把单字按钮 `☰ / 历 / 同 / ⚙` 改为 `更多 / 月历 / 同步 / 外观`，并加无障碍名称。
- `展开月历 / 桌面挂件` 改为动作明确的 `切换到月历 / 切换到桌面挂件`；`完整时间轴 ↗` 改为 `完整日历 ↗（浏览器）`，说明是外跳。
- 活动卡片的起止日期在紧凑模式下由 10 号字改为 11 号，日期不再比类型行更小。
- 插件安装说明的“从托盘退出并重启”改为指向已有的“重启游时”按钮；空状态与卡片悬停提示改为指向快捷栏“更多”，不再只靠右键。
- 快捷栏按钮沿用现有按钮样式，可用 Tab 聚焦，聚焦时边框加粗。

### U15 / U16 · 关闭行为与保存反馈

- 设置项改名为“点 × 时保留桌面挂件（不勾选则收起到托盘）”，并说明：挂件或托盘中的游时都在运行、提醒照常发送，只有“退出游时”才停止。退出按钮和托盘菜单改为“退出游时（停止提醒）”。
- 点 × 的反馈：从月历切换为挂件时提示“已切换为桌面挂件，提醒继续运行”。如果本来就是挂件（这时 × 只会收起侧栏），则说明要隐藏或退出该用哪个入口。收起到托盘时（× 设为收起，或点任一“收起到托盘”），每次运行第一次显示一条托盘气泡，说明程序仍在运行和如何退出；自检模式不弹。
- 即时保存的项（气泡、透明度、尺寸、关闭与靠边行为）在改动时提示“已自动保存：…”。页首说明颜色细节和模块布局在网页编辑，要在网页点“应用”。

## 遗留与需要 Codex 注意

1. 网页端需按约定解析 `view=timeline` 与 `date=`（第二十七节已分给 Codex）。网页支持之前，链接仍能打开，只是会忽略这两个参数。
2. 普通挂件在 320×320 时，标题和摘要占了大部分高度，活动卡片区很小（见 `quick-list-320x320.png`）。这属于桌面版的“活动区优先”，不在本轮 U01/U10 范围内，建议另列：例如低高度时把摘要收成一行。
3. 快捷栏所在的底行在普通模式下位于外框之外、是透明的（原来的图钉和菜单就在这里）。在深色主题下它和外框之间有一道浅色缝隙，桌面上透出的是壁纸。按钮自带底色，不影响使用；要不要给这一行加底色，留给外观统一时决定。
4. 没有做屏幕阅读器实测或真实高 DPI / 触屏测试。无障碍名称和提示是按代码设置的，没有用讲述人验证。
5. 托盘气泡在 Windows 10 上会显示为一条系统通知，每次运行最多一次；如果觉得打扰，可以改成只在首次使用时显示，需要往窗口偏好里新增一个布尔字段，备份校验允许这类字段。
