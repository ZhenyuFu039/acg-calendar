# U14 / U18：小挂件与可访问性续作验收

**[Codex 2026-10-27]** 按协作第二十八节继续：Claude 修改桌面端，Codex 修改网页并独立复核。本轮没有修改版本、插件 API、真实数据或网络限制，没有提交或发布。

## 网页

- 设置页签支持左右方向键、Home、End；只有选中页签进入 Tab 顺序，页签和内容区通过 ARIA 关联。游戏管理保持独立区域。
- 增加键盘“跳到活动日程”入口，默认紧凑页面也保留可访问的一级标题；焦点边框使用主题正文色，侧栏使用导航文字色。
- 手机筛选关闭时移除对话框属性，恢复背景和入口焦点；从筛选进入游戏管理时先关闭浮层，避免关闭游戏管理后回到隐藏按钮。桌面收起筛选后，手机打开面板仍能找到完整筛选项。
- 日期、入口文字、近期活动标题和截止时间随用户字号放大；手机提醒数量改为正常排列，避免盖住文字。触控模式下主要操作至少 44px 高，窄屏仍优先显示活动。
- 减少动态效果模式停用过渡与动画，不仅取消平滑滚动。

`tests/e2e-accessibility.cjs` 使用五游戏离线快照和隔离数据。最终记录与截图：`logs/uiux-accessibility/1793152473118/`。

| 检查 | 结果与范围 |
| --- | --- |
| 控件名称 | 工作台、设置、活动详情、单活动提醒、收件箱、全局通知规则、计划列表、计划编辑器、游戏管理，共 9 个状态；可访问角色中的按钮、链接、输入、选择等名称检查通过 |
| 键盘 | 页签方向键/Home/End、单一 Tab 入口、明显焦点外框、筛选首尾循环、Esc 返回入口、嵌套操作返回可见控件通过 |
| 对比 | 7 套预设 × 5 处关键文字，对最终声明的底色采样；最低约 5.77:1。关闭过渡后采样稳定颜色，不以动画中间颜色作为最终主题结论；不等同于对所有图片背景或所有自定义配色的认证 |

相关既有回归 `e2e-uiux`、`e2e-preferences`、`e2e-layout-focus`、`e2e-plugin-manager`、`e2e-plan-drawing` 均通过。后端本轮未改，不重复上一轮 315 项单元测试。

## 桌面

Claude 的实现与自测说明见 [桌面交付](uiux-desktop-small-window-2026-10-27.md)。Codex 独立构建 Release 为 0 警告、0 错误；离线隔离自检 `logs/desktop-smoke/20261028-014651-497/result.json` 为 `ok:true`，109 条活动，新增 `smallWindowVerified:true`，原有各项验证也通过。

短于 480px 的普通挂件压缩标题、摘要和状态，最多保留两个截止日期并提供查看其余日期的入口；完整说明、奖励等仍能从提示或月历找到。快捷栏大字号时可以换行，补充控件名称与明显焦点，读取系统文字大小并与主题字号结合（当前按 100%–150% 范围处理，更大值按 150% 限制）。

| 独立自检场景 | 卡片区 / 首张示例卡片 |
| --- | --- |
| 普通 320×320 | 162px / 126px |
| 同尺寸出现提示 | 136px / 126px |
| 普通 320×620 | 347px / 126px |
| 透明气泡 320×320 | 283px / 126px |
| 150% 文字模拟、普通 320×320 | 103px / 173px；卡片可滚动，五个快捷按钮可见，但不能完整放下一张 |

因此 U18 按默认字号、示例卡片验收完成；长标题、多奖励或更大系统字号不承诺整张首屏可见。

## 实机验收边界

尝试使用 computer-use 对单独复制的离线项目进行真实窗口按键检查。只读到了月历窗口的 UI Automation 树及控件名称；输入时出现 `coordinate input geometry is unavailable`，截图与一次恢复分别报 `FrameArrived timed out` / `window capture timed out`，没有完成真实按键验证。专用测试进程和后端已确认停止，记录为 `logs/uiux-accessibility/native-session.json`。

没有修改 Windows 显示缩放、系统文字大小或讲述人设置；没有读取真实 `data/`。网页 DPR/触控模拟和 WPF `MoveFocus` 不能代替以下人工验收，所以 U14 保持未完成：

- 讲述人实际朗读名称、顺序和状态变化。
- 桌面跨卡片、侧栏和快捷栏的完整物理键盘路径。
- 125% / 150% / 200% 物理显示缩放及真实系统文字大小。
- 真实触屏；原生快捷按钮当前偏向鼠标使用，尺寸取舍另需实机评估。
