# V0.2.4 · 日程工作台与桌面快捷操作

发布日期：2026-10-28。本版包含 v0.2.0 后的桌面补齐、备份恢复改进、明日方舟官网采集和 UI/UX 调整。插件 API 仍为 1，已有活动 ID、个人状态、计划和主题继续兼容。

## 主要变化

- **网页任务导航**：日程、个人计划、游戏管理、设置分区；同步与提醒常驻，备份恢复独立。默认活动区在 1440×900、五游戏测试快照下由约 372px 增至 541px。
- **截止总览**：月历显示明确截止、兑换密度与计划标记；查看某天不再自动隐藏其他活动。时间轴日期为只读时间尺，有截止才显示明细按钮；只有“只看这一天”才保存共享聚焦。
- **日期操作更稳定**：日期全览保留筛选，清除筛选保留视图和日期窗口。修复较晚返回的全览操作覆盖新月份、日期深链接首次未立即显示及月历统计日期格式不一致。
- **桌面快捷栏**：普通列表、透明气泡和月历固定提供气泡、同步、完整日历、置顶、更多。窗口模式、透明度和尺寸先于高级主题，设置按页记忆滚动，关闭与自动保存有反馈。
- **短窗与键盘**：低于 480px 的普通挂件压缩重复说明，把高度留给卡片；快捷栏大字号可换行。补充桌面控件名称、焦点样式与系统文字缩放；网页增加页签方向键、主内容跳转、焦点恢复和触控入口。
- **官网公告与头图**：明日方舟优先读取官网目录和活动预告，解析卡池、签到、分段开放及兑换时间；有效日期先入库，再逐张补图。整轮共享 16 张图片预算，支持下次续补，保留历史 PRTS 数据及署名。
- **桌面功能补齐**：原生插件列表、提醒游戏范围、同步阶段与最近备份；插件设置后可重启应用。网页恢复先预览差异，窗口偏好交接、重试和连续恢复得到修正。
- **手机与刷新**：筛选浮层不推走日程，详情与编辑采用底部弹层；日期及活动标题跟随字号。状态 ETag 减少无变化传输，保存与轮询交错时保留新状态。

## 下载与运行

在 [GitHub Release](https://github.com/ZhenyuFu039/acg-calendar/releases/tag/V0.2.4) 下载 `Playtime-V0.2.4-windows-x64.zip`，完整解压到新目录，并可用同名 SHA256 附件核验。

这是**需要运行环境的 Windows x64 便携包**，不是自带环境的安装器：

1. 安装 Python 3.11+ 与 .NET 10 Desktop Runtime x64。
2. 在解压目录运行 `python -m pip install -r requirements.txt`，安装 Windows 的 IANA 时区数据。
3. 双击 `Playtime.cmd`。桌面程序已编译，不需要 .NET SDK；网页模式可使用 `start.ps1`。

两个内置日历：明日方舟国服、终末地国服。包内另外预装 NIKKE 国际服、碧蓝航线国服、绝区零国服 JSON 插件。初始 `data/` 只包含公开插件，不含个人数据库、笔记、设置或日志。

## 从旧版升级

1. 从托盘退出旧程序；网页用户停止旧后台。
2. 程序退出后备份旧目录整个 `data/`；也可额外使用个人数据备份功能。
3. 新版解压到新目录，迁移旧 `data/` 并保留数据库、窗口偏好及自定义插件；不要用新包初始数据覆盖旧数据。
4. 按需更新新包 `plugins/` 中的公开插件到新目录 `data/plugins/`，避免覆盖自行修改的插件。
5. 从新目录启动。版本变化后首次启动生成升级前个人备份；首次需重新检查来源时仍遵守错峰与限流。

## 验证和边界

发布使用隔离数据完成 315 项后端测试、全部 22 组浏览器回归和发布二进制的离线自检；没有对来源网站反复联网测试。功能验收详见 [UI/UX 记录](../uiux-implementation-2026-10-27.md) 和 [可访问性续作](../uiux-accessibility-2026-10-27.md)。

- 讲述人、物理触屏、高 DPI 与完整桌面实际按键仍待人工验收；模拟和程序化焦点检查不代表这些项目已通过。
- 320×320 默认字号可完整显示一张示例卡片；长卡片或 150% 文字仍需滚动。系统文字大小当前按 100%–150% 范围处理。
- Windows 任务栏时钟的系统日历面板没有直接接入；可使用自身挂件、月历和 ICS 导出。
- 插件安装、卸载和启停需要重启；没有在线插件市场或任意代码插件。
- 便携包需要上述 Python 与 .NET 运行环境。备份不包含插件文件和公告图片缓存；升级前保留完整旧数据目录。
- 官网连接、公告解析和图片匹配可能失败或滞后；继续使用保守复查与站点限流，失败时保留已有日历。具体活动情况请参考游戏官方时间。
