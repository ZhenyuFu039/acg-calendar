# v0.2.0 · 个人规划、备份恢复与插件管理

本版将 v0.1.0 之后的源码功能整理为一次兼容更新。插件 API 仍为 1，既有活动 ID、个人标记、计划及主题设置继续使用；不需要 AI API 或游戏账号。

## 主要变化

- **个人规划**：先打开“◇ 个人规划”查看全部计划，选择创建后在时间轴拖出游玩时段；支持表单、编辑、移动和删除。计划总览按当前时间线列出期间可参与活动，并优先展示手动关联项。
- **备份恢复**：“数据与同步”提供个人数据备份、下载与恢复。版本变化后首次启动和恢复前会先备份；恢复失败回滚。备份不包含公告快照、图片缓存或插件文件本身。
- **插件管理**：设置或侧栏“管理日历插件”查看加载情况，单独启用、停用；重启后生效。停用和移出插件文件夹都保留个人记录。异常插件、中文及含空格文件夹可管理。
- **提醒范围**：选择全部已安装游戏、跟随当前组合或独立自选。普通搜索、类型和完成状态筛选不改变提醒范围。
- **清楚的同步状态**：活动日期先入库，图片继续补齐；展示阶段、来源等待原因和本轮结果。默认 24 小时后另加 0–2 小时随机错峰，可选 18 小时；同站默认至少 10 秒，另加随机间隔。
- **网页与桌面体验**：宽屏标题与个人计划摘要更紧凑，手机默认近期截止；无变化刷新保留节点和焦点。月历溢出、筛选隐藏和其他版本的新增活动都有说明。桌面靠边收起/展开加入动画。
- **活动时间与头图**：校正和实际开服时间按显示时区输入，并校验夏令时；碧蓝航线增加保守的跨语言头图对齐和国服公告共用主视觉。

## 下载与首次使用

在 [GitHub Release](https://github.com/ZhenyuFu039/acg-calendar/releases/tag/v0.2.0) 下载 `Playtime-v0.2.0-windows-x64.zip`，并将全部内容解压到新目录。

这是**需要运行时的 Windows x64 便携包**，不是自带运行环境的安装器：

1. 安装 Python 3.11+ 和 .NET 10 Desktop Runtime x64。
2. 在解压目录执行 `python -m pip install -r requirements.txt`，安装 IANA 时区数据。
3. 双击 `Playtime.cmd`。程序已编译，无需安装 .NET SDK。

包中预装 NIKKE 国际服、碧蓝航线国服及绝区零国服三个 JSON 插件，另有终末地国服和明日方舟国服两个内置日历。源码归档不包含编译产物；源码用户按 [Windows 构建说明](../windows-desktop.md) 构建，并从 `plugins/` 按需安装插件。

包内 `data/` 只有公开插件文件，不包含个人数据库、笔记、窗口设置或运行日志。可用附件中的 SHA256 文件核对下载完整性。

## 从旧版升级

1. 从托盘选择“退出游时”；仅用网页时停止旧 Python 后台。
2. 手动备份旧目录整个 `data/`，不要在程序运行时复制数据库。已有备份界面时也可额外生成个人数据备份。
3. 将新版解压到另一个目录，把旧 `data/` 复制到新目录并保留原数据库、`desktop-window.json` 和自定义插件。不要用新包的初始数据覆盖旧数据。
4. 按需更新新版 `plugins/` 中的官方随包插件到新目录的 `data/plugins/`；保留自行修改的插件，避免覆盖自定义配置。
5. 从新目录启动。程序检测版本变化后会生成升级前个人数据备份，已有设置和活动状态沿用。插件启停和提醒选择继续保留。

自动备份不替代退出程序后对整个旧数据目录的备份。历史 v0.1.0 标签和附件保持原样。

## 当前边界

发布检查：277 项后端测试、17 组浏览器回归及 WPF 离线隔离自检通过；测试使用独立数据，不对真实信息站施加测试流量。

- Windows 任务栏时钟的系统日历面板尚未直接接入；可使用自身挂件、月历及 ICS 导出。
- 插件安装、卸载和启停都需重启；尚无在线市场、自动更新或任意代码插件。
- 插件管理、备份和提醒范围的完整编辑在网页设置中；桌面相应入口打开本机网页。桌面尚未提供原生插件列表、原生备份恢复或提醒游戏勾选器。
- 自动个人数据恢复不恢复插件文件或桌面窗口配置；后者需从完整 `data/` 备份手动迁移。
- 手机采用表单创建规划；底部弹层、软键盘适配等仍在后续待办。
- 共享 HTTP 配额与插件切换并发保护针对同一应用实例；不承诺多个独立运行进程的全局协调。
- 公告、社区资料和图片匹配可能不完整或滞后。具体活动情况请参考游戏官方时间。
