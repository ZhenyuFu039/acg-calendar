# 绝区零 · 国服日历插件

`zzz-cn` 为声明式 JSON 包，配合当前源码新增的可信 `zzz-official` 采集引擎使用，不执行插件内脚本，不调用 AI。**V0.0.7 已包含该引擎；旧 V0.0.5 需升级主程序。**

本次 2026-10-19 样本包含 3.2、3.3 两个版本，共 25 条记录：11 条活动/丽都城募、12 条代理人/音擎调频、2 条维护。23 条有独立官方头图，维护条目不借用其他活动图片。APP 图标使用用户提供图片。新版本尚未发布的活动不会提前编造。

## 来源与规则

- 时间以[绝区零官网公告频道](https://zenless.hoyoverse.com/zh-cn/news?category=296)中文正文为准。使用官网自身公开的 `content_v2_user` JSON 接口，固定应用 ID、频道 296、语言 zh-cn，每次最多 50 条；不把 API 发布、展示过期时间当活动时间。
- `rules.json` 定义公告选择、采集范围、来源优先级及时间策略。`sources/official-news.json` 保存本次公告依据，`events.json` 是归一化结果，时间统一存 UTC。
- 识别 `【活动时间】` 区间；限时频段按正文 `「名称」调频活动` 分拆，每条使用紧随标题的图片。签到、限时玩法和丽都城募可入日历；永久剧情、商城付费礼包、预下载、社交抽奖与单独试玩条目不入日历。
- “3.x版本更新后”关联同版本更新/预下载维护公告。开始时间为维护开始加**预计**小时数，始终保留 `estimated`；不因时间经过改为确认。版本结束只采用官方明确日期，未知保留 `at:null`。例如 3.3 开服暂按 2026-10-21 11:00 UTC+8，实际以官方为准。
- [BWIKI 活动一览](https://wiki.biligame.com/zzz/活动一览)是社区整理，读取公开 MediaWiki API 的渲染表格。**只有缺图、名称与完整精确区间完全相同且唯一时**才补图；不覆盖官方时间，不用历史复刻图猜新活动。本次 Wiki 最新区间截止 9 月 14 日，已经滞后，25 条记录没有套用其历史活动。
- Wiki 保存修订 15423；活动表由 Semantic MediaWiki 动态查询生成，该修订号只固定列表模板，不能固定所有子页面数据，因此另存本次渲染快照 `sources/wiki-calendar.json`。图片依据与许可随事件保留。
- 同步失败保留上次完整日历，Wiki 或个别图片失败不阻止官方时间同步。仍未结束的缓存公告与维护上下文保留；发布者 ID 不随日期/正文编辑变化，个人收藏、完成状态与笔记保留。
- 主程序负责按用户时区转换（含夏令时）、组合时间线、收藏、筛选、提醒与 ICS。精确截止可提醒；预计维护结束不发精确提醒，ICS 跳过含未确认端点的条目。

## 本地安装

将整个 `zzz-cn` 文件夹放入主程序 `data/plugins/`，重启主程序。可在网页或桌面端选择“绝区零 · 国服”；“同步资料”会重新读取官方公告。自定义 data-dir 时使用该目录下的 `plugins/`。

目录 `assets/` 为缓存的 PNG/JPEG 图片；只访问官方 `fastcdn.hoyoverse.com/content-v2/nap/` 与 BWIKI `patchwiki.biligame.com/images/zzz/`，限制响应大小、超时与跳转目标，不执行公告 HTML。
