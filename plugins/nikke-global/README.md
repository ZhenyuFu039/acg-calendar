# 胜利女神：NIKKE · 国际服插件

数据来源：[GameKee 外服活动日历](https://www.gamekee.com/nikke/huodong/19)。这是社区整理/转载来源，不是 NIKKE 官方接口。插件使用 API 1 的 `local-json` 包和主程序内置的 GameKee 声明式采集引擎，不执行插件代码、不调用 AI、不需要游戏账号。

## 文件与安装

- `manifest.json`：游戏、区服、Logo 与来源配置；Wiki ID 为 1253，国际服 serverId 为 19（国服为 34，不混用）。
- `rules.json`：日期正则、时区、公告章节白名单、类别和拆分规则，以及采集范围。
- `events.json`：可离线加载的真实活动快照，时间统一为 UTC，保留原始时间依据和冲突。
- `sources/723266.json`：已核对公告的调度事实、段落位置和图片关联，不包含评论与用户信息。
- `assets/`：用户提供的 Logo 和匹配到的活动图片。

退出托盘中的游时后，将整个 `nikke-global` 文件夹复制到正在使用的数据目录的 `plugins/` 下（默认 `data/plugins/nikke-global/`），再启动软件；在“日历游戏”选择 NIKKE，也可勾选自选游戏组合。点击“同步资料”更新。移走目录或设置 `enabled:false` 可禁用；个人标记保留。

**V0.0.7 已包含 GameKee 引擎与本地插件图片支持**；旧 V0.0.5 需要升级。无需修改游戏注册表或重新为每款游戏编译 UI；首次加入通用引擎需要更新主程序。

## 时间与公告分析

公共活动接口返回 `begin_at`、`end_at` Unix 时间戳、`picture` 和公告链接；不用 OCR。公告按编号章节拆分，按活动名称及同一来源公告唯一匹配卡片，不进行模糊猜测。卡片头图优先，其次使用同公告章节图片；兑换、挑战可复用已证明的父活动图片，不把一张版本封面分配给所有活动。

当前 2026-10-19 快照：24 个独立条目，18 个有公告段落依据，5 张卡片匹配公告，14 个条目带头图，记录 9 处起止时间冲突。LITTLE WITCH TRICK 的挑战关卡合并到主活动详情；排除“妮姬试用功能”和“4周年情报站”。条目包括维护、活动、招募、签到、兑换、突袭和玩法更新，不代表全部历史版本。

| 情况 | 规则 |
| --- | --- |
| 维护时间标注北京时间 | UTC+8；10 月 8 日 10:00–14:00 对应 UTC 02:00–06:00，结束为预计 |
| 活动行标注 UTC+9 | 优先显式时区；未标注的当前公告规则默认 UTC+9 |
| 维护结束后开始 | 引用预计维护结束，标为预计；可在应用确认实际开服 |
| 卡片与公告不一致 | 公告优先，记录两份时间及来源；图片自带文字也可能沿用卡片旧时间 |
| 只有卡片，未核对公告 | 起止均为预计；不触发精确截止提醒 |
| 只给日期或未给时刻 | 日期级预计或待定，不推测准确开服 |
| 多期开放、兑换 | 分成独立条目，子活动记录父活动 ID；挑战关卡按 `curation` 配置合入主活动详情 |
| 无明确截止的玩法更新 | 保留为节点，不生成截止提醒 |

例如 `Cinderella Special` 公告明确截止为 **2026-12-03 04:59:59 UTC+9**，保存为 `2026-12-02T19:59:59Z`；纽约显示为 12 月 2 日 14:59:59 EST，按事件日期自动处理夏令时。卡片结束时间 `2026-12-02T16:00:00Z` 会被记录为冲突。

应用提醒只要求截止明确；ICS 导出沿用主程序较严格规则，起止都确认才导出。当前快照直接导出 6 项，18 项因预计/待定跳过；确认实际开服或手动校正后可导出更多。

## 同步边界

引擎匿名访问 GameKee 公开接口，校验 Wiki 与区服，限制抓取量、请求频率、图片类型和大小，只访问指定 GameKee/API CDN。不会读取登录凭据或执行网页代码。失败时保留已有有效数据；图片失败不阻断时间记录。

**当前公告正文 CDN 对直接程序请求会返回 HTTP 567。** 首次分析采用正常公开网页中可见的公告内容整理调度事实，缓存 `updated_at`；后续元数据未变则复用。新公告/正文改变时会尝试公开正文接口；无法读取时沿用已核对快照并提示，或将新卡片保持为预计。没有绕过验证，也不能保证未来所有新公告均可无人维护地解析。若编号、模板或接口结构变化，需要更新规则/引擎或补充经核对的来源快照。

采集最近 45 天仍相关的卡片，每轮最多 200 行、3 篇公告、24 张独立图片。超过一页时拒绝用不完整列表覆盖数据。`events.json` 整体验证成功后再原子替换；ID 与标题、日期、所属版本无关，个人收藏、完成、备注和时间校正不会被同步覆盖。

`rules.json` 的正则、默认时区、章节白名单、分类和拆分开关为可配置项；`prefer_notice`、卡片预计、未知截止不推算、唯一匹配等为当前引擎固定约束。修改规则后重启再同步，不代表任意游戏网页可以零配置解析。
