# 碧蓝航线 · 国服 JSON 插件包

以用户指定的 [BWIKI 游戏活动表](https://wiki.biligame.com/blhx/游戏活动表)发现近期国服改建公告，从公告提取限时活动及截止时间；参考 [Azur Lane Wiki Recent News](https://azurlane.koumakan.jp/wiki/Recent_News)链接的专题补充对应头图。无需 AI、登录或游戏账号。

2026-10-19 实测：6 篇国服改建公告（9 月 4 日至 10 月 15 日）解析为 **20 条活动、12 条带图片**，共 10 张独立素材。包括任务/签到、META 挑战、世界巡游、限界挑战、祈愿建造、蓝图补完、活动商店及累计奖励领取。两项维护前截止尚无明确时刻，按用户指定暂定为维护日国服 10:00，并标为预计；没有把未知当作零奖励，也没有把其他游戏货币用于本游戏。

## 使用

退出托盘中的游时，将整个目录放到当前数据目录的 `plugins/azurlane-cn/`（默认 `data/plugins/azurlane-cn/`），再启动软件。选择“碧蓝航线 · 国服”，也可勾选任意游戏组合。支持本地离线快照、网页/桌面时间条头图、详情头图、收藏、排序和统一提醒。游戏标识采用用户提供的 APP 图标 `assets/app-icon.png`，与活动头图分开处理。

**V0.0.7 已包含 `azurlane-wiki` 引擎；旧 V0.0.5 需要升级主程序**。安装文件夹不会给旧程序自动安装 Python 代码。完整本地 JSON 和图片接口仍为 API 1，无须添加硬编码的游戏选项或修改主窗口布局。

## 文件

- `manifest.json`：游戏 ID `azurlane-cn`、国服、`Asia/Shanghai` 时区和声明式来源。
- `rules.json`：日期正则、采集范围、时间策略、标题映射和逐活动的中英文图片映射。
- `rules.json.bulletin_artwork`：公告末尾共用主视觉提取规则；无独立图的同篇公告活动共用横图，保留各自时间与“共用主视觉”标记。
- `artwork-alignment.json`：可选的自动头图对齐规则，定义目录发现、批次偏移、名称/任务/奖励对象证据及冲突门槛；不包含逐活动图片 URL。
- `events.json`：可离线读取的活动快照，所有时间存为 UTC；保留原始时间、公告修订、图片 URL 和匹配依据。
- `sources/cn-bulletins.json`：用于解析及验证的国服公告 Wiki 文本和修订号。
- `sources/en-artwork.json`：从正常公开网页可见内容核对的英文专题名、头图链接及来源。
- `sources/en-artwork-live.json`：公开 API 提取的候选缓存、日期/任务上下文及修订号；随同步有限轮换复查，英文暂不可用时保留。
- `sources/cn-bulletin-artwork.json`：国服公告主视觉的真实图片地址、尺寸和文件页元数据缓存。
- `assets/`：经静态图片类型与大小检查的 PNG/JPEG 素材。

## 时间规则

| 情况 | 处理 |
| --- | --- |
| 公告明确的国服日期与时刻 | 按 UTC+8 保存；显示时按事件日期换算本机时区和夏令时 |
| “维护后”开放 | 使用该篇公告的预计维护结束，明确标为预计，不视为已确认开服 |
| “维护/维护前”结束，已有该次维护公告 | 使用对应日期的维护开始时间 |
| 只知道截止维护日期，还没有维护时刻 | 暂按国服当天 10:00，标为 `state:estimated` 并保留原文；不触发精确截止提醒，后续明确公告优先 |
| 未提供维护日期 | 保持待定，不推算下一次维护是哪天 |
| 活动商店/累计奖励领取晚于关卡关闭 | 独立列出，并记录父活动 ID |
| 自选轻量复刻 | 只列一个入口，不把七个可选活动及所有伴随活动都当作已开启 |
| 英文 Wiki 日期、UTC-7、图片内日期 | 不写入国服时间字段；英文图片只用于已核对的同一活动 |

例如“严厉女仆不严厉”的国服公告为 **10 月 15 日维护后～11 月 5 日维护**。预计开始保存为 `2026-10-15T07:00:00Z`；结束暂定为国服 11 月 5 日 10:00，即 `2026-11-05T02:00:00Z`，纽约显示为 11 月 4 日 21:00 EST，均标为预计。英文头图显示 `10/15–11/4`，属于素材文案，不能覆盖国服公告。世界巡游第三十一期的国服明确截止是 `2026-11-30T15:59:00Z`，纽约显示 11 月 30 日 10:59 EST。

提醒只对已明确的截止生效。用户指定的暂定 10:00 不作为已确认时刻触发精确提醒。ICS 导出沿用主程序更严格的起止均已确认规则，当前快照导出世界巡游和天秤座限界挑战 2 项，其余 18 项先跳过；手动确认起止后可以导出更多。所有活动详情和页面右上角展示“具体活动情况请参考游戏官方时间”。

## 自动同步与维护

当前源码支持优先保留独立活动图，再用本篇国服更新公告末尾的主视觉兜底。2026-10-22 公告末尾的 `飓风与雾霭回廊.jpg` 已实测覆盖该篇公告的 5 条活动记录；共享来源会在详情中标明，不表示这些条目各有一张独立宣传图。接口失败或未找到唯一主视觉时，继续使用原图片或无图状态；不会把图套给另一篇公告的条目。

插件通过主程序的可信 `AzurLaneProvider` 引擎匿名读取 BWIKI MediaWiki API。默认从活动表查找最近 50 天的改建公告，上限 16 篇；对仍在开放的长期 META/赛季活动保留之前缓存的公告，避免目录回看范围缩短导致消失。国服公告负责全部时间计算，**不会依赖英文站程序直读成功**。

此前英文正文直接请求曾返回防机器人页面；2026-10-23 测试公开 MediaWiki parse API 可正常获取专题，当前源码已接入可选 JSON 头图对齐。每轮先读取更新目录，再有限读取最多 6 个专题，按批次日期偏移、名称别名/任务指纹等独立证据匹配；不按列表顺序配图。冲突或证据不足时使用已有明确映射回退，否则保留无图活动。新名称、新任务句式可能仍需补充 JSON，不能保证未来所有活动无需维护。

该对齐功能尚未发布，需新源码引擎与 `rules.json.artwork_alignment` 配置同时存在；旧包不受影响。真实历史回测移除旧图片地址后，20 条记录中 8 条正确匹配、0 条错误；再移除名称别名仍可通过任务指纹识别 1 项。实现、测试和完整报告见 [头图对齐说明](../../docs/azurlane-artwork-alignment.md)。英文接口不可用时保留缓存，不阻断国服活动同步。世界巡游等尚无足够独立证据的专题仍需补充明确素材规则。

用户另提供了 [AzurLane_EN 官方 X 账号](https://x.com/AzurLane_EN)。官方 [用户动态 API](https://docs.x.com/x-api/users/get-posts)支持读取动态及关联媒体：`expansions=attachments.media_keys`、`media.fields=url,type,width,height`。需要自行配置开发者令牌，服务按 [官方计费说明](https://docs.x.com/x-api/getting-started/pricing)收费。本次匿名直读账号页面返回 403；当前包尚未接入 X，也未使用付费接口。若后续增加，可作为可选的官方图片来源，仍不采用外服时间覆盖国服时间。

新网站/公告模板的任意变化不能靠 JSON 自动理解。当前引擎按“内容新增”中的限时活动句式提取，跳过纯换装修复、付费礼包、永久功能新增等；正文未明确给出的开放期不从外服补齐。抓取/解析失败时保留上次成功日历；图片下载失败不阻断时间记录。完整快照校验通过后再替换该游戏记录，收藏、完成、备注、个人校正和其他游戏数据不受影响。
